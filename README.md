# <Red-Black-Tree-Implementation>

# Description

This project was made as part of an assignment for a CS2000 class
This project was made with the goal in mind of better understanding the searching methods used in graphs: Depth First Search and Breadth First Search 

# Usage
to test this code, there is test data within the starter code that can be used, or if you'd like to test your own data with these search methods, you can go into: 

assignment-implementing-dfs-and-bfs-starter.md

and find and alter the data shown here:

test_cases = [
        (20, 0.3, "small network (20 nodes)"),
        (200, 0.1, "medium network (200 nodes)"),
        (1000, 0.05, "large network (1000 nodes)"),
    ]

keep in mind, numbers can only be replaced with numbers, decimals can only be replaced with decimals, and strings can only be replaced with strings.
